# Space Race V2.0  (browser)

## Features
- Five mini-games: Attention, Memory, Visuospatial, Language and Reasoning.
- Difficulty scales with your saved pilot level.
- XP, levels and match count save in the browser (`localStorage`).
- Create a crew room and share an invite link.
- Up to 8 players and an end-of-match leaderboard.
- Display names only; no login or password.

## Limitations
- Keep the host's browser tab open for the whole match. If the host closes it, the room ends.
- Browser or school network restrictions will likely block PeerJS/WebRTC.
- XP is stored locally on each device (it does not sync between devices).
- This is a demonstration game, not a validated/licensed medical or diagnostic assessment.
- This is purely for conceptual purposes, to make our vision of 'Astrolympics' come to life.

## About my Code
Space Race is a interactive, browser-based cognitive assessment platform designed to reimagine astronaut health monitoring through the intersection of gamification, competition and collaborative engagement. Drawing inspiration from the Olympic Games, the concept transforms conventional cognitive testing into an immersive, progressively challenging tasks. The platform evaluates 5 key cognitive domains (attention, memory, visuospatial processing language & reasoning) through interactive challenges designed to assess different dimensions of cognitive functioning. By embedding these assessments within a structured system of progression, achievement and friendly competition, Space Race seeks to make health monitoring more engaging, accessible and intrinsically motivating.

Developed using HTML, CSS, and JavaScript, the platform incorprates dynamic difficulty progression, experience points (XP), pilot-level advancement, persistent individual progress and multiplayer crew rooms. Participants can compete in teams of upto 8 players, with performance displayed throughout through invitation links  without requiring a dedicated application server. Ultimately, Space Race aims to bridge the gap between scientific assessment and experiential engagement, demonstratong how interactive technology can foster  greater participation in astronaut health monitoring while cultivating teamwork, motivation an a collective commitment to mission readiness.
